# Промпты иллюстраций

Иллюстрации созданы встроенным инструментом image_gen; API/CLI не использовались. Итоговые файлы: `assets/exercises/*.webp`. Изображения сохранены в исходном разрешении и перекодированы в WebP (качество 88). Обрезка отдельных фаз выполняется только при просмотре в интерфейсе; исходные полосы содержат все три фазы.

Коралловая подсветка условно показывает основные работающие мышцы. Каждая иллюстрация просмотрена вместе с текстовой инструкцией. Это учебная схема, не анатомический атлас.
