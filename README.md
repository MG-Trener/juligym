# Моя домашняя тренировка

[Открыть сайт](https://mg-trener.github.io/juligym/)

Компактный конструктор домашних тренировок: **72 движения — 46 силовых и 26 растяжек**, собственный вес и две сборные гантели. Тёмная графитовая тема, лаймовые акценты и системный шрифт соответствуют MGym. Без регистрации и обязательного указания веса. Стартовые комплексы подходят для знакомства с силовыми; более сложные варианты библиотеки отмечены «После освоения базы».

## Библиотека и своё расписание

На широком экране библиотека находится слева, на телефоне открывается кнопкой «Библиотека упражнений». Сворачиваемые группы: ноги, ягодицы, спина, грудь, плечи, руки, корпус. Есть поиск по названию/мышцам, фильтры инвентаря и уровня. «+» добавляет движение сразу; название открывает картинку, дозировку, подсказки и рекомендации. У каждого движения — три фазы и полная техника.

1. Выберите количество тренировочных дней (1–7) или отметьте нужные дни в недельном блоке.
2. В «Комплексы по дням» выберите готовый вариант или «Собрать с нуля». Для каждого дня создаётся независимая копия.
3. Откройте вкладку нужного дня и добавляйте упражнения из библиотеки. Название комплекса можно изменить прямо над упражнениями.
4. При выборе движения библиотека предлагает до трёх дополнений: учитывает тип движения и состав текущего комплекса, исключает повторы. Рекомендации основаны на правилах, а не на медицинской оценке. Они не добавляются без действия пользователя.
5. Кнопки ↑ / ↓ меняют порядок; «Убрать» удаляет движение из текущего комплекса. Остальные отметки сохраняются. Редактирование уже завершённого комплекса начинает новое занятие, сохраняя историю предыдущего.

Для начала рекомендуются исходные 2–3 занятия с восстановлением; выбор 4–7 дней не является рекомендацией ежедневных силовых тренировок. При соседних днях сайт напоминает об отдыхе одной и той же группы мышц.

Расписание, названия, упражнения, отметки и история сохраняются под прежним ключом `juligym:v1`: существующие данные подхватываются без сброса. При сокращении расписания скрытые комплексы сохраняются. Печатается выбранное расписание с текущими упражнениями.

## Исходные комплексы

В разделе библиотеки **«Растяжка»** есть 26 движений по семи группам мышц: ноги, ягодицы, спина, грудь, плечи, руки и корпус. Для каждого — три фазы, условная подсветка растягиваемой области, техника и облегчение.

После силовых карточек появляется подборка до трёх растяжек для мышц выбранного комплекса. Приоритет — разным задействованным мышцам, с учётом уже добавленной растяжки. Можно добавить подборку или несколько отдельных движений из библиотеки. Указана связь «После: …», повторы исключены. Выбор сохраняется отдельно для каждого дня; ручной выбор доступен и для других групп.

Растяжка выполняется одним мягким удержанием по 20 секунд (в односторонних движениях — с каждой стороны), независимо от режима силовых подходов. Есть таймер 20/30 секунд и отдельные отметки выполнения. Добавлять растяжку можно и после завершения силовой части, без сброса её прогресса. Выбранные растяжки включаются в печатный план после силовых упражнений.

| День | Акцент | Упражнения по порядку |
| --- | --- | --- |
| 1 | Ноги и ягодицы | Приседание до стула, ягодичный мост, отжимание от стены, тяга гантели с опорой, скольжение пяткой лёжа |
| 2 | Спина и плечи | Наклон с гантелями, тяга гантели с опорой, жим гантелей сидя, подъём на носки, рука и нога на четвереньках |
| 3 | Тонус и устойчивость | Приседание до стула, отведение ноги стоя, отжимание от стены, сгибание рук с гантелями, скольжение пяткой лёжа |

Дни чередуются через день отдыха, например Пн–Ср–Пт. Первые две недели — по одному подходу с облегчённым диапазоном повторений. Затем, при хорошем восстановлении, по два. Подходы, повторения, паузы, техника и облегчения описаны в `exercises.js`.

Это общий стартовый вариант для взрослого человека без известных ограничений, а не персональная реабилитация. На сайте есть короткие указания по самочувствию и остановке занятия.

## Возможности

- От одной до семи вкладок выбранных дней и два режима нагрузки.
- 72 оригинальные иллюстрации: 46 силовых и 26 растяжек, по три фазы каждого движения с условной подсветкой мышц. Вся библиотека изображений занимает около 5,5 МБ.
- Увеличение всей иллюстрации или одной выбранной фазы.
- Отметки подходов и история завершений в `localStorage` (`juligym:v1`). Дни и режимы независимы.
- Таймер отдыха 45/60/75/90 секунд, пауза и повтор; отсчёт по реальному времени даже при уходе на другую вкладку.
- Отметки завершённых дней текущей недели, рассчитанной по местному времени браузера.
- Печать выбранного расписания с изображениями и дозировкой сразу для обоих режимов.
- Мобильный интерфейс от 320 px, управление вкладками стрелками, модальные окна с Escape, поддержка reduced motion.
- Системный шрифт и локальные изображения: сайт не обращается к сторонним API и не передаёт отметки на сервер. Между устройствами данные не синхронизируются.

## Сохранение и работа без интернета

Откройте сайт с интернетом и дождитесь внизу сообщения **«Сайт сохранён для работы без интернета»**. При первой загрузке сохраняется весь сайт и все 72 изображения. После этого тот же адрес в том же браузере открывается без сети, в том числе после закрытия браузера и перезагрузки компьютера. План и отметки сохраняются автоматически. В совместимом браузере появляется кнопка «Установить приложение»; установка не обязательна для офлайн-режима.

Кнопка «Скачать копию плана» сохраняет JSON с расписанием, упражнениями, отметками и историей; «Восстановить копию» проверяет файл и после подтверждения заменяет настройки. Очистка данных сайта, приватный режим или автоматическое освобождение хранилища браузером могут удалить локальные данные — резервная копия позволяет вернуть план. Она не включает изображения: сам сайт при необходимости загружается заново с интернетом.

Обновление загружается целиком и предлагается кнопкой «Обновить сайт»; текущая версия остаётся доступна до завершения загрузки. Неудачная загрузка не заменяет работающую офлайн-копию. Service worker ограничен каталогом сайта, поэтому не очищает кэши других приложений на том же домене.

## Запуск

Нужен Node.js 20 или новее. Установка пакетов для сайта не требуется.

```sh
npm run dev
```

Откройте `http://127.0.0.1:4173`. ES-модули нужно открывать через HTTP, не двойным кликом по `index.html`.

```sh
npm test
```

Полная браузерная проверка использует Playwright:

```sh
node scripts/browser-check.cjs
node scripts/planner-check.cjs
node scripts/stretch-check.cjs
node scripts/offline-check.cjs
```

Playwright должен быть доступен в окружении. Альтернативно задайте `PLAYWRIGHT_MODULE` — путь к установленному модулю, и `BROWSER_CHANNEL=msedge` или `chrome` для установленного браузера. `SITE_URL` позволяет проверить развёрнутый сайт. Проверка работает в изолированном браузерном профиле, не затрагивая данные пользователя. Скриншоты и пробная печать сохраняются в игнорируемый каталог `artifacts/`.

## Размещение и файлы

GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll. Все пути относительные и работают под `/juligym/`. После изменения HTML, JS, CSS или изображений выполните `node scripts/build-offline.mjs` и включите обновлённый `sw.js` в коммит. Скрипт формирует список ресурсов и версию кэша по содержимому файлов.

- `index.html` — структура, справка и модальные окна.
- `styles.css` — оформление, адаптивность и печать.
- `app.js` — взаимодействие, прогресс и таймер.
- `planner.js` — восстановление данных, расписание, группы мышц и правила рекомендаций.
- `planner.css` — компактный интерфейс конструктора и боковая библиотека.
- `exercises.js` — программа и подсказки.
- `stretches.js` — каталог растяжки, связь с тренируемыми мышцами и отдельные отметки.
- `stretch.css` — переключатель библиотеки и растяжка после силовой части.
- `catalog-extra.js` — 35 дополнительных силовых движений и 16 растяжек.
- `mgym.css` — тема MGym и компактный вид библиотеки.
- `offline.js`, `sw.js`, `manifest.webmanifest` — офлайн-копия, обновления и установка.
- `backup.js` — проверка и восстановление копии плана.
- `assets/exercises/` — итоговые WebP-иллюстрации.
- `assets/fonts/` — Golos Text и лицензия SIL Open Font License.
- `docs/image-prompts.md` — полный набор промптов и правок для иллюстраций.
- `docs/stretch-image-prompts.md` — полный набор промптов десяти растяжек.
- `docs/expanded-image-prompts.md` — промпты 51 новой иллюстрации и уточнения после просмотра.
- `docs/verification.md` — объём проведённой проверки.

## Основания программы

Общие принципы постепенного начала, контроля техники и отдыха сверены с [NHS: Strength exercises](https://www.nhs.uk/live-well/exercise/strength-exercises/) и [Mayo Clinic: Strength training](https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/strength-training/art-20046670). Конкретные комбинации упражнений, диапазоны и интерфейс составлены для этого проекта; источники не являются авторами этой программы.

Для растяжки использованы общие ориентиры [NHS: How to stretch after exercising](https://www.nhs.uk/live-well/exercise/how-to-stretch-after-exercising/) и [Mayo Clinic: Stretching](https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/stretching/art-20047931): разогретые мышцы, мягкое натяжение без боли и пружинящих движений, спокойное дыхание. Подборка по мышцам — правило интерфейса, а не индивидуальное назначение.

При расширении каталога сверены [ACE Exercise Library](https://www.acefitness.org/resources/everyone/exercise-library/) и [NASM Exercise Library](https://www.nasm.org/resource-center/exercise-library). Техническая основа офлайн-режима: [MDN Service Workers](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers) и [MDN Caching](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Caching).
