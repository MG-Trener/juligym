# Моя домашняя тренировка

Общий дневник Юли: https://juligym.mg-trener.com/

Новая реализация с нуля: тёмный графитовый интерфейс с лаймовыми акцентами, 87 домашних силовых упражнений в семи группах, отдельная иллюстрация каждого движения в трёх фазах, редактируемые подборки и расписание.

Сайт открывает экран «Сегодня» с началом или продолжением занятия. На экране «Неделя» карточка выбранной даты отделена от повторяемого шаблона — например, «План всех вторников». В него можно добавлять силовые упражнения и растяжку из иллюстрированной библиотеки. Начатое занятие сохраняет свой состав, порядок, нагрузку и прогресс.

Стрелки ↑ ↓ в карточках меняют порядок внутри силовой части или растяжки и сразу сохраняют его. После удаления доступна кнопка «Отменить»: она возвращает последнее убранное упражнение на прежнее место вместе с нагрузкой. Отмена сохраняется при перезагрузке вкладки, относится к исходному дню недели и не переписывает другие изменения. Одновременные перестановки из двух окон проверяются по версии плана.

В карточке выбранного дня подходы (1–5), повторы (число или диапазон 1–99) и удержание растяжки (5–300 секунд) сохраняются автоматически после ввода. Для динамической подвижности настраиваются повторы. У каждого дня свои значения, даже если изначально назначена одна подборка. Пошаговое занятие и таймер используют эти настройки. Начатые и завершённые занятия сохраняют прежнюю нагрузку. Ошибки ввода и связи показаны в карточке, неуспешную запись можно повторить или отменить.

В подсказке и увеличенном изображении каждого из 117 движений есть конкретный вариант «Как сделать легче». Базовые инструкции уточняют положение тела, опору и последовательность трёх фаз. Оценка «По плану» учитывает заданные подходы, повторы или секунды, обе стороны, отдых, переходы и добавленную растяжку. Для силового занятия включены 5 минут разминки, для отдельной растяжки разминка указана отдельно. Это диапазон для спокойного темпа, а не измеренное активное время: долгие перерывы между открытием и завершением страницы не показываются как длительность нагрузки.

Таймеры силового режима и растяжки сохраняют остаток на устройстве и возвращаются на паузе после перезапуска. При сворачивании таймер автоматически приостанавливается; `+15 с` не запускает его без команды. Сигнал звучит при старте, в последние 5 секунд и при завершении, звук можно отключить. Пока открыто занятие, сайт запрашивает удержание экрана и повторяет запрос после возвращения. Отказ браузера или системы показан короткой подсказкой. Таймер растяжки находится в странице и не перекрывает переход к следующему шагу.

Тихие сигналы сопровождают наведение на интерактивный элемент, нажатие и перемещение фокуса клавиатурой. Они включаются после первого взаимодействия, не звучат при вводе пароля и не повторяются при движении внутри одной кнопки. «Звуки интерфейса» отключаются в настройках; выбор хранится на устройстве отдельно от звука таймера. Ссылки на сторонние сайты из интерфейса удалены.

На ноутбуке в пошаговом силовом занятии «Подход готов» и таймер закреплены в одной компактной панели внизу экрана. При смене стороны панель показывает нужное действие; при прокрутке кнопки остаются доступны. На телефоне управление остаётся внутри страницы. Изменение размера окна не перезапускает таймер.

Переключатель «Силовые / Растяжка» расположен вверху справа. На «Сегодня» его состояние, поиск и группы слева соответствуют показанному занятию. В смешанном занятии режим меняется на растяжку после всех силовых подходов с обеих сторон. Если на сегодня назначена только растяжка, выбор «Силовые» открывает силовую библиотеку; само занятие и его прогресс сохраняются.

Левая панель показывает поиск и группы мышц выбранного каталога. На телефоне панель открывается кнопкой меню, а запрос и группа сохраняются отдельно для каждого режима при переключении.

В режиме «Растяжка» есть 30 иллюстрированных движений на семь групп мышц, готовые комплексы, личная подборка на устройстве и пошаговые занятия с таймером. Из силовой тренировки можно открыть комплекс по её группам мышц. Режим работает и офлайн после загрузки приложения и первого входа.

## Хранение занятий

Это один общий дневник без отдельных аккаунтов. При каждом открытии страницы запрашивается общий пароль. После входа посетители видят и изменяют общие подборки, расписание и отметки подходов. Завершённое занятие сохраняет название и состав упражнений на момент начала; последующие изменения подборки не переписывают историю. Календарная дата определяется в Asia/Qyzylorda.

Frontend размещён на GitHub Pages. API и PostgreSQL работают в Neon; Railway не используется. Пароль базы находится только на сервере: Neon Functions автоматически предоставляет `DATABASE_URL`. В `config.js` указан публичный адрес API, секретов там нет.

- `src/` — интерфейс, каталог, таймер и PWA.
- `media/` — 117 оптимизированных WebP, около 8,4 МБ суммарно.
- `api/index.mjs` — HTTP API, транзакции, проверка входных данных, повторных операций и версий подборок.
- `api/migration.sql` — таблицы без удаления существующих данных.
- `docs/new-image-prompts.md` — промпты генерации и исправлений иллюстраций; использован встроенный imagegen.

## Разработка и проверка

```sh
npm ci
npm run dev
npm test
npm run build
```

Локальный сайт: http://127.0.0.1:4173/. Данные по умолчанию берутся из рабочей базы. Для проверок с записью используйте исключительно отдельную ветку Neon и временно направляйте `config.js` на её API.

```sh
JULIGYM_PASSWORD=<пароль> API_URL=https://PREVIEW-FUNCTION-URL/ npm run test:api
JULIGYM_PASSWORD=<пароль> API_URL=https://PREVIEW-FUNCTION-URL/ npm run test:browser
JULIGYM_PASSWORD=<пароль> API_URL=https://PREVIEW-FUNCTION-URL/ npm run test:day-settings
JULIGYM_PASSWORD=<пароль> API_URL=https://PREVIEW-FUNCTION-URL/ npm run test:week-template
JULIGYM_PASSWORD=<пароль> API_URL=https://PREVIEW-FUNCTION-URL/ npm run test:coaching
JULIGYM_PASSWORD=<пароль> API_URL=https://PREVIEW-FUNCTION-URL/ npm run test:mobile
JULIGYM_PASSWORD=<пароль> API_URL=https://PREVIEW-FUNCTION-URL/ npm run test:interface
npm run test:desktop
JULIGYM_PASSWORD=<пароль> API_URL=https://PREVIEW-FUNCTION-URL/ npm run test:access
JULIGYM_PASSWORD=<пароль> npm run test:pwa
```

Проверки API и браузера с записью ограничены тестовой веткой `br-silent-lake-b99eu6ub`. `test:desktop` работает только с локальным сайтом и изолированными данными: проверяет закреплённое управление, стороны, отдых и удержание, прокрутку, ширины 1001–1920 px, переход на мобильную ширину, восстановление и согласованность режимов. Браузерные проверки используют Playwright и установленный Edge; путь к Playwright в скриптах соответствует среде разработки Codex на этом компьютере. Тест PWA проверяет установку, полный кэш, повторное открытие профиля без интернета и WebAudio. Результаты и снимки сохраняются в игнорируемом `artifacts/`.

## Публикация

1. Проверить изменения на отдельной ветке Neon.
2. При необходимости применить `api/migration.sql` и обновить сервер: `npm run build:api`, затем упаковать `artifacts/api-bundle/index.mjs` в корень ZIP и передать его Neon `deploy_function` с runtime `nodejs24`, slug `diary`, рабочей веткой `br-orange-silence-b96hkdjh`, проектом `dawn-recipe-63876119`.
3. Убедиться, что `config.js` указывает на рабочий API. Проверить `/health` и `/state?from=YYYY-MM-DD&to=YYYY-MM-DD`.
4. Выполнить `npm run build`, закоммитить файлы и отправить `main`. GitHub Pages публикует корень этой ветки; `CNAME` сохраняет домен.
5. Проверить опубликованный домен и обновление установленного PWA.

Изменение API не требует передачи пароля PostgreSQL браузеру или GitHub Pages. Тестовые записи не переносятся в рабочую базу.

## Офлайн и обновления

Пароль проверяется сервером, а API чтения и записи требует подписанный токен со сроком 8 часов. Токен хранится только в памяти страницы; после перезагрузки пароль запрашивается снова. Сервер хранит scrypt-проверку пароля; ключ подписи выводится из серверного DATABASE_URL. В клиентских файлах и настройках браузера пароль и токен не сохраняются. Для офлайн-входа после первого успешного входа на устройстве хранится проверочное значение PBKDF2 с индивидуальной солью. Статические иллюстрации и код сайта остаются публичными на GitHub Pages; общий пароль ограничивает интерфейс и доступ к API дневника.

Приложение кэширует интерфейс, шрифт и все иллюстрации. Последний загруженный дневник сохраняется на устройстве и доступен для просмотра после перезапуска. Общие отметки записываются только после ответа сервера; без интернета изменения отключены. При наличии новой версии на странице появляется уведомление «Обновить / Позже». Настройки и ручная проверка обновлений доступны и на маленьких телефонах. Шаг растяжки хранится в общем дневнике; на этом устройстве таймер восстанавливается на паузе. При обновлении несохранённые настройки блокируют перезагрузку. Односторонние силовые подходы сохраняют обе стороны, а частичное завершение получает отдельный статус в истории и календаре. При переходе со старой версии без пароля PWA автоматически применяет обновление и перезагружает открытые страницы; последующие обычные обновления применяются кнопкой.

Калории и другие неизмеренные показатели не выдумываются. Иллюстрации созданы ИИ, подсветка мышц условная; текстовые подсказки уточняют технику. Более сложные варианты отмечены в библиотеке и не включены в начальные комплексы.
